# Pesty 使用指南

Pesty 会自动跟随 macOS 系统外观切换亮色或暗色主题，无需单独配置。

## 系统要求

- macOS 14 Sonoma 或更高版本
- Apple Silicon 或 Intel Mac

## 安装

推荐通过 Homebrew 安装：

```bash
brew install --cask bifrost-proxy/pesty/pesty
```

也可以从
[GitHub Releases](https://github.com/bifrost-proxy/pesty/releases/latest)
下载 DMG，并将 `Pesty.app` 拖入“应用程序”目录。

社区发布使用 ad-hoc 签名，未经过 Apple 公证。Homebrew Cask 会校验
SHA-256 并移除隔离属性；直接安装 DMG 时，macOS 可能要求在
“系统设置 → 隐私与安全性”中确认打开。

## 基本使用

1. 启动 Pesty。默认情况下，应用会显示在菜单栏中。
2. 复制文本、链接、图片、文件、富文本或颜色。
3. 按 `⌘⇧V` 打开剪贴板面板。
4. 使用方向键选择内容，按 `Return` 粘贴。
5. 直接输入文字可以搜索历史记录；按 `Esc` 先清空搜索，再次按下关闭面板。

常用快捷键：

| 快捷键 | 功能 |
| --- | --- |
| `⌘⇧V` | 打开或关闭面板，可在设置中修改 |
| `⇧⌘T` | 全局翻译当前选中的文字；面板打开时翻译当前文本或图片卡片，可在设置中修改 |
| `⇧⌘D` | 全局解释当前选中的文字；面板打开时解释当前文本卡片，可在设置中修改 |
| `T` | 翻译看板打开且原文语言明确时，交换原文和目标语言 |
| `←` `→` `↑` `↓` | 移动选择 |
| `Space` | 预览或关闭预览当前内容 |
| `Return` | 粘贴当前内容 |
| `⌘1` 至 `⌘9` | 快速粘贴对应位置的内容 |
| `⌘⌫` | 删除当前内容 |
| 直接输入 | 搜索历史记录 |
| `Esc` | 清空搜索或关闭面板 |

## 设置

在菜单栏菜单中打开“设置”，可以调整：

- 全局快捷键和历史记录上限
- 是否直接粘贴到当前应用
- 是否忽略密码管理器标记为隐藏的内容
- 提示音、登录时启动和菜单栏图标
- 面板高度
- 翻译来源和目标语言，以及翻译、解释快捷键
- Apple Translation、豆包和可复用的兼容 AI 服务配置
- iCloud Drive 同步
- 中文或英文界面
- 剪贴板历史清理

如果隐藏了菜单栏图标，可以从“应用程序”中再次打开 Pesty，重新进入设置。

## 翻译与解释

在任意应用中选中文字后，按 `⇧⌘T` 可以翻译，按 `⇧⌘D` 可以获得精简解释。
全局读取文本选区需要辅助功能权限，Pesty 不会读取安全输入框中的内容。

在 Pesty 面板中选中一张文本卡片后也可以使用相同快捷键；图片卡片也可以翻译，
Pesty 会先使用 macOS Vision 在本机识别文字。也可以右键卡片选择“翻译”或“解释”。
结果会显示在选区或卡片附近；点击结果看板之外的区域会将其关闭。

- macOS 15 及以上可使用 Apple Translation。
- Apple Translation 需要对应语言包，可在“设置 → 翻译&解释”中检查和下载。
- 使用豆包翻译或解释前，需要在“设置 → 翻译&解释”中填写模型和 API Key。
- OpenAI 兼容服务当前只用于解释，需要填写接口、模型和 API Key。
- API Key 保存在 macOS 钥匙串中，不写入 Pesty 偏好设置或 iCloud。
- 调用云端服务时，只有用户主动处理的当前选中文本会发送给对应服务商。

翻译服务选择、豆包配置、支持语言、结果操作和排障步骤请查看
[翻译功能使用指南](TRANSLATION.md)。

## 辅助功能权限

“直接粘贴到当前应用”需要 macOS 辅助功能权限。Pesty 只使用该权限向之前
正在使用的应用发送粘贴快捷键。没有授权时，仍可在 Pesty 中选择内容并手动粘贴。

## iCloud 同步

iCloud 同步默认关闭。开启后，Pesty 会通过你自己的 iCloud Drive 在 Mac 之间
同步历史记录、Pinboard 和历史记录上限。保留数量采用最后修改的设置，并在所有
同步设备上使用同一个生效时间，避免不同设备反复删除或恢复超出上限的记录。
快捷键、登录启动、辅助功能权限、菜单栏显示、面板高度和界面语言仍由每台 Mac
分别保存。使用前需要在系统设置中登录 iCloud 并启用 iCloud Drive。

## 应用更新

Pesty 在启动时和每小时检查一次更新，也可以在“设置 → 关于”中手动检查。

- 显示菜单栏图标时，更新入口位于菜单栏菜单。
- 隐藏菜单栏图标时，更新入口位于剪贴板面板顶部。
- 点击更新后，Pesty 会下载并验证发布包，替换应用，然后自动重启。
- Stable 与 Beta 通道相互隔离；Stable 不会收到 Beta，Beta 只更新到后续 Beta。

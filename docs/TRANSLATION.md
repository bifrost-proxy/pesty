# Pesty 翻译功能使用指南

Pesty 可以直接翻译任意应用中选中的文字，也可以翻译剪贴板历史中的文本，不需要先
把内容粘贴到其他应用。默认全局翻译快捷键为 `⇧⌘T`。

## 快速使用

### 翻译其他应用中选中的文字

1. 在浏览器、文档编辑器或其他应用中选中一段文字。
2. 按 `⇧⌘T`。
3. Pesty 会在选区附近显示翻译看板，并自动开始翻译。
4. 查看译文后，点击“复制译文”将结果复制到系统剪贴板。

读取其他应用的文本选区需要 macOS 辅助功能权限。首次使用时，请按照提示在
“系统设置 → 隐私与安全性 → 辅助功能”中允许 Pesty。Pesty 不会读取安全输入框
或密码框中的选中文字。

### 翻译剪贴板历史

1. 按 `⌘⇧V` 打开 Pesty，选中一张含有文本的卡片。
2. 按 `⇧⌘T`，或右键卡片并选择“翻译”。
3. 翻译看板会显示在当前卡片上方，并自动开始翻译。

翻译入口只对含有文本的卡片可用，例如文本、富文本和链接卡片；图片和不含文本
的文件不能直接翻译。

默认快捷键 `⇧⌘T` 在其他应用和 Pesty 面板中都可以使用，可以在
“设置 → 翻译&解释 → 翻译快捷键”中修改。

## 支持的语言

Pesty 当前提供以下语言选项：

- 英语
- 中文（简体）
- 日语
- 韩语
- 法语
- 德语
- 西班牙语

原文语言还可以选择“自动”。最终是否支持某个语言组合，也取决于当前选择的翻译服务。

## 选择翻译服务

可以在“设置 → 翻译&解释 → 翻译偏好”中设置默认服务，也可以在翻译看板右上角
的“更多”菜单中临时切换。

| 服务 | 适用条件 | 行为 |
| --- | --- | --- |
| 自动 | 推荐选项 | 在 macOS 15 及以上优先使用 Apple Translation；如果 Apple Translation 不可用、语言包缺失或语言组合不受支持，并且豆包已经配置，则自动改用豆包。macOS 14 上会使用已配置的豆包，否则提示没有可用服务。 |
| Apple Translate | macOS 15 或更高版本 | 使用 macOS 提供的 Apple Translation 框架。未配置豆包也可以使用；需要先下载对应语言包。 |
| 豆包（火山方舟） | 所有受支持的 macOS 版本 | 需要用户自己的火山方舟 API Key 和模型 ID。当前选中的文本会发送到火山方舟完成翻译。 |

OpenAI 兼容服务目前不处理翻译请求。它位于同一设置页中，但当前只用于“解释”
功能；翻译请使用 Apple Translation 或豆包。

## 配置 Apple Translation

Apple Translation 不需要在 Pesty 中填写 API Key：

1. 确认当前系统为 macOS 15 或更高版本。
2. 打开“设置 → 翻译&解释”。
3. 将“翻译服务”设为“Apple Translate”。
4. 选择默认原文语言和目标语言。
5. 在“Apple 翻译语言包”区域检查“默认必备”和“当前语言选择”。
6. 对显示“尚未下载”的语言包点击“下载”，并保持设置窗口打开，直到显示
   “已下载，可以使用”。
7. 返回任意应用选中文字，或在 Pesty 中选择文本卡片，然后按 `⇧⌘T`。

如果所选语言组合不可用，可以更换原文或目标语言，或者配置豆包后改用豆包。
“自动”模式下，Apple Translation 执行失败时会尝试回退到已配置的豆包。

Pesty 会始终检查英语与简体中文基础语言包，同时检查当前选择的语言组合。原文设为
“自动”时，实际识别出的语言可能还需要额外语言包；如需提前下载，请先选择明确的
原文语言。下载完成后，可以将翻译服务改回“自动”。

## 配置豆包（火山方舟）

使用前需要准备火山方舟 API Key，以及一个可调用的方舟模型 ID。

1. 打开“设置 → 翻译&解释”。
2. 在“豆包（火山方舟）”区域点击“获取 API Key”，前往火山方舟控制台创建或查看
   API Key。
3. 将 API Key 填入 Pesty，点击旁边的“保存”。
4. 填写方舟模型 ID 并点击“保存”。界面中的示例为 `doubao-seed-evolving`，
   实际请使用自己账号下可用的模型 ID。
5. 确认设置页显示“豆包翻译已就绪”。
6. 将“翻译服务”设为“豆包（火山方舟）”，或保留“自动”作为 Apple Translation
   不可用时的后备服务。

API Key 会保存在 macOS 钥匙串中，保存后不会在界面中再次显示；需要更新时点击
“更换 API Key”。模型 ID 和服务选择保存在当前 Mac，不会同步到 iCloud。

## 在翻译看板中操作

- 切换顶部的原文或目标语言会立即按新设置重新翻译。
- 原文和目标语言都已明确选择时，点击中间的交换按钮或按 `T` 可以交换语言并重新翻译。
- 从右上角“更多 → 翻译服务”切换服务后，会立即重新翻译。
- 译文区域支持文本选择，也可以点击“复制译文”复制完整结果。
- 翻译失败时点击“重试”；如果当前没有可用服务，可以直接从看板打开“翻译设置”。
- 翻译、解释和完整内容预览不会同时显示，打开其中一个会关闭另外两个。
- 按 `Esc`、点击看板外区域、点击关闭按钮，或再次按全局翻译快捷键即可关闭看板。

## 隐私说明

- 使用 Apple Translation 时，Pesty 通过系统 Translation 框架提交当前文本。
- 使用豆包时，只有用户主动选择并调用翻译的当前文本会发送到火山方舟。
- Pesty 不会为翻译批量上传剪贴板历史、Pinboard、图片或文件。
- 全局翻译会优先通过辅助功能接口读取选中文字。对于不能直接读取选区的应用，Pesty
  可能临时触发一次复制，并在读取后完整恢复原有剪贴板内容；临时内容不会写入历史。
- Pesty 不会读取或翻译安全输入框中的内容。
- 豆包 API Key 保存在 macOS 钥匙串，不会写入偏好设置、剪贴板存储或 iCloud。
- 译文只有在用户点击“复制译文”后才会写入系统剪贴板。

更多数据处理说明请查看[隐私说明](PRIVACY.md)。

## 常见问题

### 提示先选中需要翻译的文字

在当前应用中没有检测到文本选区。请重新选中文字，再按全局翻译快捷键。部分应用
不向辅助功能接口公开选区，Pesty 会尝试安全的复制回退；如果应用禁止复制，仍无法
读取选区。

### 提示需要辅助功能权限

打开“系统设置 → 隐私与安全性 → 辅助功能”，为 Pesty 开启权限后重试。

### 提示“请选择一条文本剪贴内容进行翻译”

当前卡片没有可翻译文本。请选中文本、富文本或包含文字的链接卡片后重试。

### 提示没有可用的翻译服务

macOS 14 不支持 Apple Translation，请配置豆包。macOS 15 及以上可以选择
Apple Translate；如果仍不可用，请确认系统版本并尝试更换语言组合。

### 提示 Apple 翻译语言包尚未下载

打开“设置 → 翻译&解释”，将翻译服务切换为“Apple Translate”，在语言包区域下载
“默认必备”和当前语言组合。下载时保持设置窗口打开。

### 豆包显示“请配置 API Key 和模型 ID”

API Key 和模型 ID 必须分别保存。填写后请确认设置页出现“豆包翻译已就绪”。

### 豆包返回 HTTP 错误或翻译失败

检查网络、API Key、模型 ID、账号配额和模型调用权限，然后在翻译看板中点击“重试”。
Pesty 的错误日志不会记录原文、译文、API Key 或服务响应正文。

### Apple Translation 不支持当前语言组合

更换原文或目标语言；也可以配置豆包，并将翻译服务切换为“豆包”或“自动”。
